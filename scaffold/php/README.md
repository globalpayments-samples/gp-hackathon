## Setup

**1. Copy the environment template:**

```bash
cp .env.example .env
```

**2. Fill in your sandbox credentials:**

```env
GP_APP_ID=your_app_id_here
GP_APP_KEY=your_app_key_here
GP_API_ENVIRONMENT=sandbox
```

Get credentials from the [GP Developer Portal](https://developer.globalpayments.com).

**3. Install dependencies and start:**

```bash
composer install
./run.sh           # http://localhost:3000
```

Or start manually:

```bash
composer install
php -S 0.0.0.0:3000 router.php
```

> Do **not** set `GP_ACCOUNT_NAME` — the SDK auto-detects the correct account from

> info do not match" errors.

## SDK configuration

`core/config.php` configures the GP API SDK from environment variables:

```php
$config = new GpApiConfig();
$config->appId   = $_ENV['GP_APP_ID'];
$config->appKey  = $_ENV['GP_APP_KEY'];
$config->channel = Channel::CardNotPresent;
$config->environment = (strtolower($_ENV['GP_API_ENVIRONMENT'] ?? 'sandbox') === 'production')
    ? Environment::PRODUCTION
    : Environment::TEST;

ServicesContainer::configureService($config);
```

## Endpoints

### `GET /api/access-token`

Returns a short-lived, scope-restricted access token for the Hosted Fields frontend.
The token is limited to `PMT_POST_Create_Single` — the Drop-In UI uses it to
tokenize the card without raw PAN ever reaching this server.

**Response:**
```json
{
  "accessToken": "uua7....",
  "environment": "sandbox"
}
```

---

### `POST /api/charge`

Charges a tokenized card reference produced by the Hosted Fields UI.

**Request body:**
```json
{
  "token": "PMT_xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "amount": "29.99",
  "currency": "USD"
}
```

**Success response:**
```json
{
  "transactionId": "TRN_abc123xyz",
  "status": "CAPTURED",
  "responseCode": "SUCCESS",
  "authorizationCode": "123456"
}
```

**Error response (`400` / `502`):**
```json
{
  "error": {
    "type": "GatewayException",
    "message": "INVALID_REQUEST_DATA - Token does not exist",
    "status": 502
  }
}
```

## Troubleshooting

**`composer: command not found`**
Install Composer: `php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');" && php composer-setup.php --install-dir=/usr/local/bin --filename=composer`

**"Missing required environment variables: GP_APP_ID, GP_APP_KEY"**
Copy `.env.example` to `.env` and fill in your credentials. The server will refuse
to start with missing required vars.

**`GET /api/access-token` returns `500` — "Connection error"**
Check that `GP_APP_ID` and `GP_APP_KEY` are correct. Confirm `GP_API_ENVIRONMENT=sandbox`
matches the credential set you copied from the developer portal.

**Drop-In UI iframe does not render**
The hosted-fields iframe requires the access token to carry `PMT_POST_Create_Single`
permission. Verify the token response contains `accessToken` (not just `token`) and
that the frontend reads the correct field.

**"Access token and merchant info do not match"**
Remove or comment out `GP_ACCOUNT_NAME` from `.env`. The SDK must auto-detect the
account — setting it manually causes this error.

**Port 3000 already in use**
Set a different port: `PORT=8080 php -S 0.0.0.0:8080 router.php`
or edit `run.sh` to change the default.
